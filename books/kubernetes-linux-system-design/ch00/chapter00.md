# 第0章 はじめに

## この本について

本書「Kubernetes × Linux システム設計 2025」は、**KubernetesとLinuxを軸に**、現代的なクラウドネイティブ基盤を設計・構築する方法を体系立てて解説する指南書です。

### 2025年、なぜ今「Kubernetes × Linux システム設計」なのか

2025年、Kubernetesの地位は揺るぎないものになりました。CNCFの調査では、**Argo CD**がKubernetes GitOpsの大多数採用ソリューションとなり、**eBPF**がK8s ネットワークの標準技術の1つとして定着しました。AI/MLワークロードは、もはやK8s上での主要なユースケースの1つです。

しかし、Kubernetesの導入と運用は簡単ではありません。Linuxの知識が不十分なままK8sに触れると、なぜデプロイが失敗するのか、なぜネットワークが繋がらないのかの根本原因が特定できません。本書は両方を一緒に学ぶことで、**本質的な理解**を得られるように設計されています。

### 本書の対象読者

本書は以下の方を対象としています：

- Linuxの基礎は知っており、それをKubernetesでどう活用するか学びたい方
- すでにKubernetesに触れたが、背後のLinuxの仕組みを深く理解したい方
- クラウドネイティブ基盤の設計者・運用者として、現場の知識を強化したい方
- FinOps、オブザーバビリティ、GitOpsなど、現代的なプラクティスを体系的に学びたい方

### 必要となる前提知識

以下の基本的なコンピュータリテラシーを持っていてください：

- Linuxのコマンドライン（bash/cd/grep/catなど）
- クラウドコンピューティングの基本概念
- HTTP/HTTPS、ネットワークの基礎（IP/ポート/DNS）
- Dockerまたはコンテナの基本概念
- YAMLファイルの基本

## 本書の構成

本書は全10章で構成されます。

### フェーズ1: 基盤と核心（第1章〜第3章）
- なぜ今、Kubernetesなのか
- Linuxカーネル → コンテナの仕組みを追って理解
- Kubernetesの核心アーキテクチャ/APIオブジェクト

### フェーズ2: パターンと実践（第4章〜第6章）
- K8sで頻用するリソースのパターン
- ネットワークの設計とeBPF
- GitOps（Argo CD）による運用自動化

### フェーズ3: 現代的な運用（第7章〜第10章）
- K8s上でのAI/MLワークロード
- FinOpsによるコスト管理
- オブザーバビリティ基盤
- 基盤を0から設計→構築→監視する総合力

## 進め方のヒント

- 各章の末尾に**演習**があります。実際に手を動かさずにはK8sは理解できません。
- Kubernetesは**多層的なシステム**です。各層の相互作用を意識してください。
- 演習はminikubeやkindなどのローカル環境でも実行可能です。
- CNCFプロジェクトの英語ドキュメントも併せて参照してください。

本書を通じて、2025年のクラウドネイティブ時代に対応できるシステム設計力を身につけてください。
