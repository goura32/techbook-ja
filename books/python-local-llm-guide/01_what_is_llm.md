## LLM（大規模言語モデル）の基本概念

### LLMとは

LLM（Large Language Model）とは、膨大な文章のデータで学習したAIモデルです。文章の理解、生成、要約、翻訳など、多くの言語タスクをこなすことができます。

### Transformerの仕組み

LLMの基礎はTransformerアーキテクチャです。

1. **トークン化**：テキストを小さい単語の組み合わせ（トークン）に分割
2. **エンコーディング**：トークンに数値（ID）を割り当て、ベクトル化する
3. **アテンション**：文脈の中でどの単語に注目するかを計算
4. **デコーディング**：出力ベクトルを文章に戻す

### ローカルLLMの意義

LLMをローカルで動かすメリット：
- **プライバシー保護**：データを外部に送信しない
- **コスト削減**：API利用料が不要
- **カスタマイズ**：独自のデータで学習・調整できる
- **オフライン動作**：インターネット接続が不要
- **即時応答**：ネットワーク遅延がない

### テキスト生成の仕組み

LLMがテキストを生成する際には、以下のステップを踏みます。

1.  **入力：** 入力テキストをトークンに分割
2.  **エンコーディング：** トークンを数値ベクトルに変換
3.  **推論：** モデルのパラメータを用いて次のトークンを推測
4.  **デコーディング：** トークンをテキストに戻す

このように、LLMは次の単語を確率的に選ぶことで文章を生成します。温度パラメータを調整することで、生成の多様性をコントロールできます。

### Transformerアーキテクチャの概要

Transformerは17年に発表された論文「Attention Is All You Need」で提案されたニューラルネットワークのアーキテクチャです。

**主要な構成要素：**

- **Attention（自己注意機構）：** 文の各部分を関連つけて文脈を理解
- **Multi-head Attention：** 複数のAttentionを同時に実行
- **Position Embedding：** 単語の位置情報をベクトルに付加
- **Feed Forward Network：** 各トクンの情報を処理

### ローカルLLMの特徴

ローカルLLMは、以下のような特徴があります。

1. **オフライン対応：** インターネット接続がなくても使用可能
2. **プライバシー保持：** データが外部に送信されない
3. **カスタマイズ可能：** 独自のデータでファインチューニング可能
4. **高速応答：** ネットワークの遅延がない

### モデルの選定基準

モデルを選ぶ際、以下の基準を考慮します：

| 基準 | 説明 |
|------|------|
| パラメータ数 | 大きいほど知能が高いが、メモリも必要 |
| 推論速度 | パラメータ数が少ないほど速い |
| メモリ要求 | VRAMの容量に合わせる |
| 言語サポート | 日本語対応度 |
| コミュニティ | サポートの充実度 |
