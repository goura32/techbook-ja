# 第1章 LLMとは何か

## ローカルLLMが注目される理由

本章では、LLM（大規模言語モデル）の基本と、なぜローカルでの運用が重要になってきたかを理解します。

### LLMの仕組みを直感的に理解する

LLM（Large Language Model、大規模言語モデル）は、膨大な量のテキストデータから「言葉の統計的パターン」を学習し、人間のような文章を生成できるAIモデルです。具体的には、以下のようなしくみで動作しています。

```
入力: 「日本を訪れた旅行者が最も最初に訪れることは何か」
        → モデルが内部の重みパラメータを走査
        → 「富士山」の次に「東京タワー」が来る確率が高い
        → 「京都」が最も高い確率を持つ → 出力
出力: 「日本を訪れた旅行者が最も最初に訪れるのは、東京です。」
```

LLMは正解を知っているわけではありません。過去の学習データの中から「最も確からしい次の言葉」を次々につなげて文章を生成しているのです。

モデルの規模（パラメータ数）が増えれば増えるほど、文章の表現力は向上しますが、必要な計算量とメモリも比例して増大します。

### ローカルLLM vs クラウドLLM

| 比較項目 | ローカルLLM | クラウドAPI |
|---------|------------|-------------|
| データの外部送信 | 不要 | 必須 |
| インターネット | 不要 | 必須 |
| コスト | 初期投資のみ | 従量課金 |
| カスタマイズ | 自由 | 制限あり |
| 処理速度 | ハードウェア依存 | ネットワーク依存 |
| 継続利用 | 永続的 | API終了で利用不可 |

## モデルのサイズと性能の関係

LLMはパラメータ数によって複数のサイズに分類されます。

### 主要なパラメータ数と用途

| パラメータ数 | 例 | メモリ必要量 | 用途 |
|------------|-----|------------|------|
| 1B～3B | Gemma 2B | 2～6GB | 基本的な文章生成 |
| 7B～13B | Llama 3.2 | 4～16GB | 一般的なタスク |
| 30B～70B | Llama 3.1 | 16～40GB | 高度な推論 |
| 200B～1T | GPT-4 | 数百GB | 最先端推論 |

### メモリ必要量の計算

ローカルでLLMを動かす際に必要なメモリ量（VRAMまたはRAM）は、以下で概算できます。

```
必要メモリ(GB) ≒ パラメータ数(10億) × 2Byte × 1.25
```

「× 2Byte」はfp16（半精度浮動小数点）での重みサイズ。
「× 1.25」は推論時のオーバーヘッド分です。

例: Llama 3.2の7Bモデルの場合
```
7 × 2 × 1.25 = 17.5GB
```

このため、少なくとも16GB以上のメモリが必要です。

## 用語の整理

本書で頻出する用語をまとめます。

- **モデル**: 学習済みのAIの本体。「_weights_」「重み」とも呼ばれる
- **トークン**: 文章を切り分けた最小単位。1トークン≒0.7語
- **推論**: モデルに入力を与えて出力を生成すること
- **ファインチューニング**: モデルを特定のタスクに合わせて追加学習すること
- **プロンプト**: モデルに入力する指示文
- **コンテキストウィンドウ**: モデルが一度に処理できるトークンの最大数
- **.quantization（量化）**: 数値の精度を下げてメモリ使用量を減らす技法

## ローカルLLMの利点と課題

### 利点

1. **プライバシーが守られる**: 入出力データが外部に流れない
2. **オフラインで利用できる**: インターネット接続不要
3. **コストが predictable**: 一度ハードを購入すれば利用し放題
4. **完全なカスタマイズ**: モデルの内部構造を改造できる
5. **APIの制約がない**: スロットリング・課金上限なし

### 課題

1. **ハードウェアコスト**: 高性能GPUは高い
2. **学習コスト**: セットアップに時間がかかる
3. **性能の限界**: クラウドモデルの最新モデルと比べると劣る場合がある
4. **メンテナナンス**: モデルの更新を手動で行う必要がある

## まとめ

本章で学んだこと：

- LLMは膨大なテキストから言葉のパターンを学習したモデルである
- パラメータ数が増えると性能が向上するが、メモリ使用量も増加する
- ローカルLLMはプライバシー、コスト、カスタマイズ性の面で優れる
- ただしハードウェア要件が高く、セットアップが難しい
