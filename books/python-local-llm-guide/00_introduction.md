# 第0章 はじめに

## この本について

本書「Pythonで学ぶローカルLLM構築入門」は、AIモデルを自前の環境で構築・運用する方法を、初心者でも実践的に学べるよう設計されたガイドブックです。

近年、ChatGPTやGeminiといった大規模言語モデル(LLM)の登場により、自然言語による対話システムが身近になりました。しかし、クラウドAPIに頼った利用方法には、いくつかの課題があります。

- **データプライバシー**: 企業の機密情報や個人のプライバシーに関わる情報を、外部サーバーに送信できない
- **コスト**: 大容量のAPI利用では、使用量に応じて課金される
- **接続依存**: インターネット接続が切れると利用不可
- **カスタマイズ制限**: APIの制約により、モデルの内部構造や動作を自由にカスタマイズできない

本書では、これらの課題を解決する方法として、**ローカルLLM**の構築手法を Python を中心に解説します。ローカルLLMとは、自身のPC（パソコン）やオンプレミスサーバーで動作するAIモデルのことです。インターネットにつながなくても動作するため、プライバシー面でも優れています。

## 対象読者

本書は以下のような方を対象としています。

- Pythonを基本的な構文（変数、関数、クラス）を知っている方
- AIや機械学習に初めて touch する方
- 自分のPCでAIモデルを使いたいと考えている方
- クラウドAPI に頼らない自律的なAIアプリケーションを作りたい方

## 必要となる環境

本書をすすめるために、以下の環境を用意してください。

### ハードウェア要件

- **CPU**: Intel Core i5 以上（M1/M2以降のApple Siliconも対応）
- **メモリ**: 8GB 以上（16GB推奨）
- **ストレージ**: 空き容量 20GB 以上
- **GPU（任意）**: NVIDIA GeForce RTX 3060 以上（CUDA 12対応）

GPUがある場合、推論速度が数倍～数十倍に向上します。ただし、CPUだけでも十分動作します。

### ソフトウェア要件

- **OS**: Windows 10/11、macOS 12以降、Ubuntu 20.04以降
- **Python**: 3.10 または 3.11（最新版推奨）
- **pip**: Pythonのパッケージインストーラー（通常Pythonに同梱）
- **git**: バージョン管理ツール

## 本書の構成

本書は全10章で構成されます。各章は独立したテーマを持ち、順に進めていくことでスキルが積み上がっていく構成になっています。

- **第1章～第3章**: LLMの基本と環境構築
  - LLMとは何かを理解し、開発環境を整えます。
- **第4章～第6章**: LLMの導入とPython連携
  - モデルを選択し、Pythonから実際に呼び出す方法を学びます。
- **第7章～第9章**: 実践的な応用
  - RAG（文脈参照）やプロンプトエンジニアリング、GPU利用などを扱います。
- **第10章**: 最終プロジェクト
  - これまでの知識を総動員して、チャットボットを構築します。

## 進め方のヒント

- コード例はすべて動作確認済みです。自分のPCでも同じ手順で実行してください。
- 各章の最後に演習問題があります。必ず実際に手を動かしてください。
- GPUがない場合、演習で時間がかかるものはCPUモードで動作します（速度は遅くなります）。
- 不明な点があれば、公式ドキュメントを併せて参照してください。

本書を通じて、AIモデルを自在に操る力を身につけてください。では、はじめましょう。
