# 第0章 はじめに

## この本について

本書「Rustシステムプログラミング入門」は、Rust言語を使って本格的なシステムプログラミングを学ぶためのガイドブックです。

### なぜRustなのか

Rustは**3年連続「最も憧れの言語」**に選ばれ、TIOBE指数では**過去最高の順位**を記録しました。Linuxカーネルに公式採用され、Firefox、Chrome、Windowsなどの主要プロジェクトで本格採用が進む中、Rustは単なる「新しい言語」ではなく**システムプログラミングのデファクトスタンダードに**なりつつあります。

しかし、Rustを学ぶ際にもっとも障壁となるのが**所有権システム**です。C/C++では未定義動作として放置されていたメモリ安全性の問題を、コンパイル時に強制するため、「慣れないと書けない」という課題があります。

本書は、この所有権システムを**理解できるまで粘り強く解説**することで、Rustをマスターするための最短ルートを提供します。

### 本書の対象読者

本書は以下の方を対象としています：

- C/C++を知っていて、安全なシステムプログラミング言語を学びたい方
- Rustに興味はあるが、所有権システムに挫折した経験のある方
- システムプログラミングの基礎を理解し、最新のツールで開発したい方
- ハードウェア制御、OS開発、ネットワークプログラミングなどの本格的なシステム開発に興味がある方

### 必要となる前提知識

以下の基本的なプログラミング概念を理解していることを前提としています：

- 変数、関数、制御構文(if/while/for)
- クラスとオブジェクト指向プログラミング
- データ構造（配列、リスト、ハッシュテーブル）
- ポインタとメモリの基本概念
- Make/CMakeなどのビルドシステム

Rustの構文に不慣れでも、C/C++などの他の言語でプログラムを書いた経験があれば、本書からRustを学ぶことができます。

## 本書の構成

本書は全10章で構成されます。

- **第1章～第3章**: Rustの基本と開発環境
  - なぜRustなのかを理解し、開発環境を整え、基本的な構文を学びます。
- **第4章～第6章**: Rustの核心（所有権、並行性、型システム）
  - Rust最大の特徴である所有権システム、非同期処理、型システムの仕組みを深く学びます。
- **第7章～第9章**: 実践的な技術
  - C/C++連携、性能最適化、エラーハンドリングを実践的に扱います。
- **第10章**: プロジェクト
  - 本書で学んだすべてを総動員して、実際のシステムアプリケーションを構築します。

## 進め方のヒント

- Rustは**書いたまま動かない言語**でもあります。エラーメッセージと格闘しながら進めてください。
- 各章に**演習問題**があります。必ず手を動かして試してください。
- `cargo` コマンドラインツールは、本書を通じて頻繁に登場します。
- Rustの公式ドキュメント（https://doc.rust-lang.org/）も併せて参照してください。

本書を通じて、メモリ安全性を保ちながら驚異的な性能を実現するRustの力を手に入れてください。
